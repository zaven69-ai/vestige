# Temple d'Auguste et de Livie — miniature 2.5D

Original procedural geometry and renders made for Vestige. Present restored building, simplified proportions, not a certified ancient reconstruction. The blue/gold circular base is interface decoration. See `docs/design/TEMPLE-MINIATURE-V1.md` for references and limits.

- `temple-miniature-source.blend`: editable Blender source.
- `temple-miniature-source.glb`: static source model, **not loaded on the map**.
- `view-0…7.png`, `@2x`, `@3x`: transparent native bitmap families, 128/256/384 px.
- `preview.png`: larger 768 px illustration for the existing POI sheet.
- `build-info.json`: reproducible build metadata.

No third-party mesh or image texture is embedded. Reference photographs keep their own licenses; none is redistributed in this pack. Original code, geometry and renders in this pack are provided under MIT, see LICENSE.txt.
